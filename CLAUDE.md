# Sherpa

Part of a hackathon hub. Shared context: `../HACKATHONS.md` (targets, deadlines, decisions).

## Conventions
- All code, docs, commit messages and file contents are in English. Chat with the owner is in Vietnamese.
- The PRODUCT is English only, everywhere: what the tutor writes and says, hints, errors, the wake word and the speech recogniser (the owner decided for all demos and tests). The prompt tells the model to answer in English whatever language the screen or the question is in; a test keeps that rule in place.
- Domain vocabulary is in `CONTEXT.md`; use those terms.

## Where context lives
- Spec: `.scratch/sherpa/spec.md`
- Tickets: `.scratch/sherpa/issues/NN-<slug>.md` (each has a `Status:` line)
- To resume work: read the spec, then open tickets whose Status is not resolved; take the lowest number that is unblocked.
